# Symbol files (`.ecadsym`)

Each symbol is a standalone UTF-8 JSON `.ecadsym` (or `.json`) file. A symbol library is a directory of these files with no manifest required:

```text
my-library/
  test-point.ecadsym
  buffer.ecadsym
```

See the [example symbol directory](../packages/web/public/examples/symbols) (`test-point.ecadsym`, `buffer.ecadsym`) or use **Download example** in the UI.

## Libraries and editing

Manage libraries under **Settings → Symbol libraries** (or **Projects → Symbol libraries**):

- **Built-in library** — Contains **66 read-only symbols** generated by [`@ecad/default-symbols`](../packages/default-symbols/README.md) (passives, diodes, transistors, switches, power/ground, connectors, op amp, flash, regulator, RP2040/RP2350, Nordic nRF54L/nPM2100 packages, and Box). Export them as standalone `.ecadsym` files with `pnpm run symbols:generate /absolute/path/to/output`.
- **Creating symbols** — Choose **New symbol** in the project sidebar to open an empty `.ecadsym` in the borderless symbol editor, or select two or more schematic shapes and click **Create symbol** in Attributes.
- **Editing symbols** — Select a placed symbol and click **Edit symbol** in Attributes to edit writable user, project, or desktop directory definitions. Changes autosave and refuse to overwrite externally modified files.

## User and project configuration

Libraries load in order: enabled **user libraries** first, then enabled **project libraries**. Later definitions override earlier ones with the same ID (project overrides user), while built-in symbol IDs remain reserved.

- **Web** — User configuration lives in `localStorage` (`ecad.user-config.v1`, synced across tabs). Directory uploads import a snapshot as embedded symbols.
- **Desktop** — User configuration lives in `symbol-libraries.json` in the platform config directory (`~/.config/ecad`, `~/Library/Application Support/ecad`, or `%APPDATA%\ecad`). **Add library directory** binds a live directory on disk; **Reload libraries** rereads files.
- **Project** — Stored in `symbol-libraries.json` (referenced by `.ecadprj`'s `symbolLibraries` field), plus standalone project symbols listed in `symbols`.
- **External directory trust (desktop)** — Project library paths inside the project folder load automatically. Paths resolving outside the project (`..`, absolute, `~/`, or symlinks) prompt for approval before reading or writing, stored per project/directory pair in `approved-libraries.json` in the user config directory (never inside the project).

Example configuration (`symbol-libraries.json`, max 32 libraries per scope, 10 MiB total):

```json
{
  "version": 1,
  "symbolLibraries": [
    {
      "id": "builtin",
      "name": "Built-in symbols",
      "enabled": true,
      "source": { "kind": "builtin" }
    },
    {
      "id": "my-parts",
      "name": "My parts",
      "enabled": true,
      "source": { "kind": "directory", "path": "~/symbols/my-parts" }
    }
  ]
}
```

Uploaded libraries use `"source": { "kind": "embedded", "symbols": [...] }`.

## File schema

```json
{
  "format": "ecad-symbol",
  "version": 1,
  "units": "mm",
  "id": "custom.connector",
  "name": "Connector",
  "description": "Single connection point",
  "prefix": "J",
  "value": "1 pin",
  "shapes": [
    { "kind": "rectangle", "x": 0, "y": 0, "width": 2, "height": 2 },
    { "kind": "wire", "x1": -2, "y1": 0, "x2": -1, "y2": 0 },
    { "kind": "pin", "name": "IN", "number": "1", "x": -2, "y": 0 }
  ]
}
```

All fields above are required except optional `footprint` and `attributes`. Unknown fields are rejected.

| Field | Rules |
| --- | --- |
| `id` | 1–64 chars: `[a-z][a-z0-9._-]*` (e.g., `custom.connector`). |
| `name` | 1–100 chars, non-whitespace. |
| `description` | Up to 500 chars (may be empty). |
| `prefix` | 1–16 chars: `[A-Za-z][A-Za-z0-9_]*` (instances number as `J1`, `J2`, …). |
| `value` | Default value, up to 100 chars (may be empty). |
| `footprint` | Optional default footprint: `{ "library": "builtin" \| "project", "id": "<footprint-id>" }`. |
| `attributes` | Optional map of up to 32 custom attributes (1–64 char names, case-insensitively unique, cannot be digits-only or `name`/`reference`/`value`; values up to 2,000 chars). Copied to new placements; net symbols omit extra attributes. |
| `shapes` | Up to 256 primitives in millimetres relative to origin `(0, 0)`, positive Y up. |

## Drawing primitives

Default stroke width is `0.254 mm` (optional positive `lineWidth` up to `1000 mm`). Bounds: coordinates `-1000..1000 mm`, dimensions/radii `0.01..1000 mm`, lines/wires length `>= 0.01 mm`, rotations `-360..360` degrees.

| `kind` | Required fields | Optional fields |
| --- | --- | --- |
| `wire` / `line` | `x1`, `y1`, `x2`, `y2` | `lineWidth` |
| `rectangle` / `triangle` | `x`, `y` (center), `width`, `height` | `rotation` (deg CCW), `filled`, `lineWidth` |
| `circle` | `x`, `y` (center), `radius` | `filled`, `lineWidth` |
| `text` | `text`, `fontSize`, `x`, `y`, `width`, `height` | `rotation` (deg), `horizontalAlign` (`left`/`center`/`right`), `verticalAlign` (`top`/`middle`/`bottom`) |
| `pin` | `x`, `y` (terminal center) | `name`, `number`, `length` (mm, default `2` for new pins), `rotation` (deg), `electricalType`, `activeLow`, `showName`, `showNumber`, `showLabels` (legacy), `labelOffset` (legacy point-only) |

- **Pins** — Fixed `0.254 mm` terminal radius. Wires connect only to `pin` terminals (never to decorative `line`/`wire` primitives). `electricalType` accepts KiCad's 12 types (`input`, `output`, `bidirectional`, `tri-state`, `passive`, `free`, `unspecified`, `power-in`, `power-out`, `open-collector`, `open-emitter`, `no-connect`; default `passive`).
- **Active-low & overbars** — `activeLow: true` draws an overbar on the pin name and a `0.635 mm` inversion bubble at the body end of the lead. Text and net labels also render KiCad's `~{…}` overbar markup.
- **Pin label visibility** — `showName` and `showNumber` override legacy `showLabels` (default `true`).

## Symbol references, overrides, and locks

Schematics and nested symbols reference definitions by `{ library: { scope: "user" | "project", id }, definitionId }` instead of copying geometry:

```json
{
  "kind": "symbol",
  "library": { "scope": "user", "id": "builtin" },
  "definitionId": "resistor",
  "x": 0,
  "y": 0,
  "rotation": 90
}
```

- **Instance overrides** — Placements store position, rotation (degrees in `.ecadsym`, radians in `.ecaddraw`), attributes, footprint, `textPositions`, `textAlignments`, `lineWidth`, and `childOverrides` (keyed by `shape:<localId>` or `attribute:name|reference|value`, rotations in radians).
- **Nesting limits** — Circular references are rejected; max nesting depth is 32 and max resolved primitives is 65,536.
- **Locks** — Standalone items default to unlocked; within a symbol, non-text children default to locked while text/attribute labels default to unlocked. Locked top-level items require **Select locked items** in the toolbar to select; child locks always protect children from local edits.

## Import rules

- One symbol per file; max 100 files and 1 MiB per import/directory/browser cache.
- Symbol IDs must be unique within a library and cannot collide with reserved built-in IDs.
- All files in a batch validate atomically; any invalid file or duplicate ID leaves the existing library unchanged.
- Multi-symbol library files are not supported.
